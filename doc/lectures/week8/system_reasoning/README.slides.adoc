== Tradeoffs
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
| Approach | Strength | Weakness | Use
| Baseline | Easy | Hides timing | First pass
| Guarded | Protects invariant | Needs modeling | State changes
| Retry-safe | Handles duplicates | More control state | Queues
| Observed | Strong evidence | More logging | Defense
|===
