== Trade-Offs
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach
|Strength
|Weakness
|Use when

|Simple baseline
|Easy to explain
|Hides timing assumptions
|First pass only

|Guarded transition
|Protects the invariant
|Needs careful state modeling
|State changes matter

|Explicit coordination
|Makes dependencies visible
|Can add waiting
|Ordering is required

|Observability-first
|Produces strong evidence
|Adds instrumentation work
|Defense matters
|===
