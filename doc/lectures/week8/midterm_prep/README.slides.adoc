= Midterm Preparation: How to Think, Not Memorize

== Lecture Focus

[.column]
* Analyze pressure, not just the happy path.
* Identify the invariant before choosing a fix.

[.column]
* Use evidence to defend the design.
* Connect the reasoning to A1.

== The Question Behind the Question

[.column]
* Do not memorize terms without context.
* State the hidden assumption.
* Identify the pressure that breaks it.

[.column]
* Show the evidence.
* Explain the trade-off.
* Defend the correction.

== Comparison of Approaches

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach
|Strength
|Weakness
|Best Use

|Simple baseline
|Easy to explain
|Hides pressure assumptions
|First pass

|Guarded transition
|Protects the invariant
|Needs careful state modeling
|State changes

|Explicit coordination
|Makes ordering visible
|May add waiting
|Multi-step workflows

|Observability-first
|Produces clear evidence
|Adds instrumentation work
|Defense and validation
|===
