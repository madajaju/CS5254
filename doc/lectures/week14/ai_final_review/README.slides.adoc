== Worked Example

== Problem Setup

* Reflection: A1 accepted AI's fix; it failed
* Verification: Rejected AI's "Distributed Saga" for local stress test

== Naive Implementation

* Assumption: Operation happens once, in order
* Code invisible: Method name sounds correct
* Sequential test passes

```text
actor performs operation
system reads current state
system applies transition
system emits side effect
```

== Failure Scenario

* Overlapping execution, delayed delivery expose stale state
* Failure not syntax bug; design assumption mismatch

== Corrected Design Direction

* Name invariant and make transitions observable
* Add correctness controls: version checks, idempotency, coordination

== Why Improved Design Is Safer

* Proves invalid interleavings rejected or recovered
* Focus shifts from hope to evidence-based design

== Failure Modes

* Symptom: Single happy-path success
  * Detection: Repeated runs with concurrent actors
  * Correction: Add failure-focused tests targeting invariant

* Symptom: Tool, not design property named
  * Detection: Ask which invariant is protected
  * Correction: State invariant first, select mechanism later

* Symptom: Vague evidence undermines claims
  * Detection: Reviewer cannot reconstruct failure
  * Correction: Capture structured evidence linking to claims

* Symptom: Fix changes behavior without comparison 
  * Detection: No before/after runs using same workload
  * Correction: Keep failing test, run after redesign

== Trade-Off Analysis

[cols="1,1,1,1", options="header"]
|===
| Approach | Strengths | Weaknesses | When to Use
| Simple baseline | Easy to explain and implement | Hides timing and pressure assumptions | First implementation
| Guarded state transition | Protects invariant | Requires careful modeling | Status changes
| Explicit coordination | Makes dependencies visible | May cause waiting or deadlock | Multi-object workflows 
| Idempotent design | Handles duplicates | Requires keys or control | Queues and async workers
| Observability-first design | Strong evidence | Adds instrumentation | Assignments needing proof
|===
