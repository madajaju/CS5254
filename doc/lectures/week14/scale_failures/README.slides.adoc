== Trade-Offs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach |Strength |Weakness |Use when

|Simple baseline |Easy to explain |Hides pressure assumptions |First pass and comparison
|Guarded state transition |Protects invariant |Needs careful state modeling |Status and workflow steps
|Explicit coordination |Makes dependencies visible |Can bottleneck or deadlock |Ordering matters
|Observability-first |Strong evidence |Adds instrumentation work |Need proof for review
|===
