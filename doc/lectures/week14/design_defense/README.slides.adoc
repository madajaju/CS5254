== Trade-Offs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach |Strengths |Weaknesses |Use When
|Simple baseline |Easy to explain |Hides timing assumptions |First pass
|Guarded transition |Direct invariant protection |More state modeling |Workflow steps
|Explicit coordination |Visible ordering |Can bottleneck |Multi-object flows
|Observability-first |Strong evidence |More instrumentation |Defend with logs
|===
