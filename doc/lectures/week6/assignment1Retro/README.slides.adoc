== Ownership Analysis

=== Weak Design


[.stretch]
[plantuml, weak-ownership, svg]
----
@startuml
skinparam shadowing false
skinparam roundcorner 10
skinparam backgroundColor transparent
top to bottom direction

rectangle Student
rectangle Course
rectangle EnrollmentManager

Student --> Course : requests change
Student --> EnrollmentManager : also mutates state
Course --> EnrollmentManager : also mutates state

note right of EnrollmentManager
Weak design:
multiple actors can change the same state.
end note
@enduml
----

Everyone modifies enrollment.

Nobody owns enrollment.

=== Strong Design

[.stretch]
[plantuml, strong-ownership, svg]
----
@startuml
skinparam shadowing false
skinparam roundcorner 10
skinparam backgroundColor transparent
top to bottom direction

rectangle Student
rectangle Course

Student --> Course : requests enrollment change
Course --> Course : validates invariant
Course --> Student : returns result

note right of Course
Strong design:
one owner enforces the invariant
and prevents invalid state.
end note
@enduml
----

Course owns enrollment.

Course enforces invariants.

== Weak vs Strong AI Critique

=== Weak Critique

[source]
----
AI suggested ConcurrentHashMap
----

[plantuml, weak-ai-critique, svg]

[AI Suggestion] --> [Thread-Safe Collection]
[Thread-Safe Collection] --> [Feels Correct]
[Feels Correct] --> [Invariant Still Broken]

note bottom of [Invariant Still Broken]
Thread safety is not the same as correctness.
end note
@enduml
----

=== Strong Critique

[source]
----
AI assumed thread safety
would preserve correctness.

It ignored the invariant that
only one worker may claim work.

The recommendation solved
a symptom, not the root cause.
----

[plantuml, strong-ai-critique, svg]
----
@startuml
skinparam shadowing false
skinparam roundcorner 10
skinparam backgroundColor transparent
top to bottom direction

[AI Recommendation] --> [Assumption Check]
[Assumption Check] -> [Invariant Check]
[Invariant Check] --> [Ownership Check]
[Ownership Check] -> [Valid Design Decision]

note right of [Invariant Check]
Good critique asks whether the recommendation
preserves correctness, not just performance.
end note
@enduml
----

== AI Review Checklist

=== Before Accepting AI Recommendations

[%step]
* What assumptions is AI making?
* What invariant is AI protecting?
* What invariant is AI ignoring?
* Who owns the state?
* Can ownership remove sharing?
* What tradeoffs exist?
* How will we validate correctness?
