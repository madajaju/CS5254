== Trade-Off Comparison
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach
|Strength
|Weakness
|Best Use

|Simple baseline
|Easy to build
|Hides pressure assumptions
|First draft

|Guarded transition
|Protects invariant directly
|Needs careful modeling
|Stateful workflows

|Explicit coordination
|Makes ordering visible
|Can create waiting
|Multi-object steps

|Observability-first
|Strong evidence
|Extra instrumentation
|Validation and defense
|===
