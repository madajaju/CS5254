= Missed Signals

== Opening Narrative
* Two components each wait for the other to make progress.
* Logs show activity, but the workflow never completes.
* The code looks locally reasonable.
* The coordination contract is incomplete.
* The design question is how to make progress observable and defensible.

== Trade-Off Comparison
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach
|Strengths
|Weaknesses
|When to use

|Simple baseline
|Easy to explain
|Often hides timing assumptions
|First pass comparison

|Guarded transition
|Protects the invariant directly
|Requires careful state modeling
|Workflow steps and reservations

|Explicit coordination
|Makes dependencies visible
|Can add waiting or bottlenecks
|Multi-object ordering

|Observability-first
|Produces strong evidence
|Adds instrumentation work
|Failure proof and review
|===
