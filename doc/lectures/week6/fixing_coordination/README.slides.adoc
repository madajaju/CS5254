= Fixing Coordination

== Coordination Under Pressure
[.column]
* Two components wait on each other
* Logs show activity, but progress stops
* The code can look correct on the happy path

[.column]
* The real question is about the invariant
* What must remain true when timing changes?
* What evidence proves the design is safe?

== Trade-Off Summary
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach |Strength |Weakness |Best use

|Simple baseline |Easy to explain |Hides pressure assumptions |First pass

|Guarded transition |Protects the invariant directly |Needs careful state modeling |Stateful workflows

|Explicit coordination |Makes ordering visible |Can add waiting or deadlock risk |Multi-object dependencies

|Idempotent design |Handles duplicates and retries |Needs keys and deduplication |Async and external calls
|===
