== Trade-Offs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach |Strengths |Weaknesses |When to use
|Simple baseline |Easy to explain |Hides pressure assumptions |First pass and comparison
|Guarded transition |Protects invariant directly |Needs careful state modeling |Status changes and workflow steps
|Explicit coordination |Makes dependencies visible |Can add waiting and bottlenecks |Multi-object ordering
|Observability-first |Strong evidence for review |Adds instrumentation work |Failure proof and defense
|===
