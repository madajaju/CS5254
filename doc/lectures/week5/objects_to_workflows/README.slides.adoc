== Naive Implementation

Assumptions that operations are sequential and state is current:
- Actor performs operation
- System reads current state
- System applies transition
- System emits side effect

== Failure Scenario

Conditions like overlap or delay reveal issues: 
- Operation observes stale state 
- Executes twice or arrives late  
- Workflow may become stuck

== Improved Design Direction

* Name the invariant 
* Make transitions observable
* Add controls: version checks, idempotency, explicit coordination

== Why Improved Design Is Safer

* Moves from hoping to proving correctness under interleavings
* Creates defenses against invalid operational scenarios

== Failure Modes and Anti-Patterns

* **Symptom**: Passes a single happy-path demonstration  
  * Why: Test avoids timing and pressure  
  * Detect: Add concurrent actors, stress tests  
  * Correct: Add failure-focused tests targeting invariant

* **Symptom**: Names a tool, not a design property  
  * Why: Focus on tools over invariants  
  * Detect: Ask about invariant protection  
  * Correct: Write invariant first

* **Symptom**: Vague evidence lacks detail  
  * Why: Logs miss critical identifiers  
  * Detect: Reviewer's inability to reconstruct failure  
  * Correct: Capture structured evidence linked to claims

* **Symptom**: Changes behavior without comparison  
  * Why: Failure not repeatable  
  * Detect: No before/after testing  
  * Correct: Keep and rerun failing tests

== Trade-Off Analysis

[cols="3,3,3,3", options="header"]
|===
| Approach | Strengths | Weaknesses | When to Use
| Simple baseline | Easy to implement | Hides timing assumptions | First implementation
| Guarded state transition | Protects core invariant | Requires careful modeling | Status changes
| Explicit coordination | Makes dependencies visible | Possible bottlenecks | Multi-object workflows
| Idempotent design | Handles duplicates | Requires deduplication | Queues, retries
| Observability-first design | Strong evidence | Adds instrumentation work | Assignments needing design defense
|===
