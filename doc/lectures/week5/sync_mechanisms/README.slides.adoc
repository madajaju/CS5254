* Shared state needs protection

* Protect a small critical section
* Guard an invariant, not a method name
* Risk: blocking, deadlock, hidden serialization

* Always re-check the condition
* Risk: lost wakeup, spurious wakeup, stuck workflow

== Tradeoffs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
| Approach | Strength | Weakness | Use
| Baseline | Simple | Hides timing | First version
| Guarded state | Protects invariant | Needs modeling | Workflow steps
| Coordination | Makes order visible | Can block | Shared resources
| Retry-safe | Handles duplicates | Needs keys | Queues, calls
| Observed | Strong evidence | Adds logging | Design defense
|===

== Evidence Needed

* Correlation ID
* Entity ID
* State before and after
* Lock or wait event
* Timing and worker identity
* Before/after test run
