== What is System Stress?
* Stress appears when demand approaches or exceeds capacity
* Symptoms include latency growth, queue buildup, and errors
* Causes can be traffic spikes, slow dependencies, or resource contention
* The goal is to find safe operating limits before users do

== Load Testing Basics
* Start with realistic user journeys
* Increase traffic gradually and repeatably
* Measure throughput, latency, and error rate
* Keep test data and environment as stable as possible
* Stop when you reach a known limit or unsafe behavior

== Observability Under Stress
* Use metrics to detect saturation early
* Use logs to explain errors and retries
* Use traces to follow slow calls across services
* Alert on rate changes, not only on outages
* Correlate signals before and after the load increase
