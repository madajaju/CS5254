== Testing and Monitoring Checklist

* Define the workload before running tests.
* Measure latency, throughput, and error rate.
* Watch CPU, memory, disk, and network.
* Compare expected and observed behavior.
* Capture logs and traces for root cause analysis.
* Adjust capacity or controls based on findings.
