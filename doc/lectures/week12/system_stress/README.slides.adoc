= What is System Stress?

== Topic Overview

[.column]
* Stress reveals hidden limits
* Contention exposes shared-resource pressure
* Saturation turns added work into worse performance

[.column]
* Edge cases appear under timing pressure
* Operational pressure changes behavior
* Evidence must be repeatable and structured

== Design Trade-Offs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach
|Strength
|Weakness
|Best Use

|Simple baseline
|Easy to explain
|Hides pressure assumptions
|First comparison point

|Guarded transition
|Protects the invariant directly
|Needs careful state modeling
|Workflow steps and status changes

|Explicit coordination
|Makes dependencies visible
|Can bottleneck or deadlock
|Multi-object ordering

|Idempotent design
|Handles duplicates and retries
|Needs keys and deduplication
|Queues and external calls
|===

== Summary

[.column]

* Trade-offs must be stated clearly
* The design must be defensible
