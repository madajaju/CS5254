== Trade-Off Comparison
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach |Strength |Weakness |Best Fit
|Simple baseline |Easy to explain |Hides pressure assumptions |First pass
|Guarded transition |Protects invariant directly |Needs careful state modeling |Stateful workflow
|Explicit coordination |Makes dependency visible |Can add waiting |Ordering requirement
|Idempotent design |Handles duplicates |Needs deduplication |Retries and async work
|===
