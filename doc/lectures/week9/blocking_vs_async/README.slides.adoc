= Blocking is the Enemy of Scale

== Lecture at a Glance
* Blocking appears harmless in a single workflow.
* Under load, it can saturate workers and stall progress.
* The real question is whether the invariant still holds.
* Evidence must show the failure, not just the happy path.
* Design responses trade peak throughput for controlled behavior.

== Trade-Off Analysis
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach
|Strengths
|Weaknesses
|When to Use

|Simple baseline
|Easy to explain
|Hides pressure assumptions
|First comparison point

|Guarded transition
|Protects the invariant
|Needs careful state modeling
|Workflow state changes

|Explicit coordination
|Makes dependencies visible
|Can create waiting
|Multi-object ordering

|Observability-first
|Strong evidence for review
|Adds instrumentation work
|Stress and validation
|===
