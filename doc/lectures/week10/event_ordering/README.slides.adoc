== Why It Breaks

* Delivery order is not logical order
* Fast workers can outrun slow ones
* Old events can overwrite new state
* Happy-path tests hide timing pressure

== Hidden Assumption

* “First sent” does not mean “first handled”
* “Handled” does not mean “committed”
* “Committed” does not mean “acknowledged”
* Time can split delivery from causality

== Tradeoffs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
| Approach | Strength | Weakness | Use
| Baseline | Simple | Hides timing | First version
| Guarded | Protects invariant | Needs modeling | State changes
| Idempotent | Retry-safe | Extra storage | Queues and retries
| Observed | Strong evidence | More logging | Review and defense
|===
