== Evidence and Trade-Offs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
|Approach |Strength |Weakness |Use When

|Simple baseline
|Easy to explain
|Hides timing pressure
|First comparison point

|Guarded state transition
|Protects the invariant
|Requires state modeling
|Workflow steps

|Explicit coordination
|Makes ordering visible
|Can bottleneck
|Multiple dependent objects

|Idempotent design
|Tolerates retries
|Needs keys or deduplication
|Queues and async workers
|===
