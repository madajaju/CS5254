== Why It Matters

* Looks correct once
* Breaks under retries
* Hidden assumption
* Concurrency pressure
* Evidence must survive failure

== Retry Storms

* Many failed workers retry together
* Downstream load spikes
* Duplicate work appears
* Progress can stall

== Tradeoffs

[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
| Approach | Strength | Weakness | Use
| Baseline | Simple | Hides timing | First version
| Guarded | Protects invariant | Needs modeling | State changes
| Idempotent | Survives retries | Needs keys | Queues, workers
| Observed | Strong evidence | Adds logging | Design defense
|===
