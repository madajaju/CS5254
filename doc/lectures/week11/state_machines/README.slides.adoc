== Failure Scenario

[.column]
--
* Two workers read the same state
* Both attempt the same transition
* Duplicate work starts
--

[.column]
--
* Winner is hidden in logs
* Pressure: overlapping execution
* Root cause: check and update split apart
--

== Response

[.column]
--
* Guard the transition
* Use an atomic update or single owner
* Keep IDs and states in logs
--

[.column]
--
* Re-run the same pressure test
* Reject stale or competing transitions
* Preserve evidence for review
--

== Tradeoffs
[.stretch]
[cols="1,1,1,1", options="header", width="100%"]
|===
| Approach | Strength | Weakness | Use
| Baseline | Simple | Hides timing | First version
| Guarded | Protects invariant | Needs modeling | State changes
| Coordinated | Visible order | Bottlenecks | Multi-object flow
| Observed | Strong evidence | Adds logging | Design defense
|===
