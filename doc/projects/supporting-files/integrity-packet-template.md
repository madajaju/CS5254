# Integrity Packet Template

Use this template for A0 and extend it for every assignment.

## 1. Recommendation

What design decision did you make?

## 2. Assumptions

What assumptions are you making?

Include assumptions about:

- concurrency model
- shared state
- ordering guarantees
- failure behavior
- runtime environment
- AI-generated code or advice

## 3. Evidence

What evidence supports your decision?

Include:

- code references
- tests
- logs
- diagrams
- observed behavior
- benchmarks, if applicable

## 4. Validation

How did you verify correctness?

Include:

- unit tests
- stress tests
- race-condition checks
- failure injection
- manual reasoning
- AI-assisted critique and your response

## 5. Ownership

Who is accountable for the design and implementation?

For individual assignments, this is you.

## 6. Escalation Path

Where could this design fail?

What should a reviewer, maintainer, or future engineer watch for?

## 7. AI Collaboration Log

Document:

- prompts used
- AI-generated recommendations
- what you accepted
- what you rejected
- what you verified manually
