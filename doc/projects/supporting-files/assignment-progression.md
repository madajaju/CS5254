# Assignment Progression

All assignments build on the same evolving system.

## A0 — Individual Integrity Packet

Create your personal reasoning and validation model.

## A1 — Object Model Under Concurrency

Design a clean object-oriented system, then introduce concurrency.

Expected focus:

- object boundaries
- shared state
- invariants
- synchronization needs

## A2 — Coordinated Object Systems

Extend the A1 system with multiple interacting components.

Expected focus:

- coordination
- ordering
- locks, monitors, or synchronizers
- deadlock risk

## A3 — Asynchronous System Design

Transform the system into an asynchronous or event-driven model.

Expected focus:

- futures/promises/tasks/events
- non-blocking interactions
- throughput vs complexity
- duplicate or out-of-order events

## A4 — Capstone System

Extend the system under full stress.

Expected focus:

- partial failure
- retries
- recovery
- observability
- runtime differences
- final system defense
