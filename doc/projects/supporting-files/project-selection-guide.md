# Project Selection Guide

Choose a project domain that interests you, but make sure it gives you enough concurrency pressure to satisfy the course goals.

A strong project domain includes:

- shared mutable state
- multiple actors or workers
- ordering constraints
- long-running or asynchronous operations
- partial failure scenarios
- opportunities for object-oriented redesign

You may propose a custom project, but it must demonstrate equivalent complexity and receive instructor approval.

## Required Across All Projects

Your system must evolve through:

- A1: Object model under concurrency
- A2: Coordinated object systems
- A3: Asynchronous/event-driven design
- A4: Full system under stress

You may not restart the system between assignments without instructor approval.
