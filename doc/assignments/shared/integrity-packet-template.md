# Integrity Packet Template

Use this template for every assignment.

## 1. Recommendation
What design decision did you make?

## 2. Assumptions
What must be true for this design to work?

Include:
- runtime assumptions
- concurrency assumptions
- data/state assumptions
- AI/tool assumptions

## 3. Evidence
What evidence supports your decision?

Include:
- tests
- logs
- traces
- metrics
- screenshots if helpful

## 4. Validation
How did you verify correctness?

Include:
- test commands
- expected results
- failure cases tested
- limits of your validation

## 5. Ownership
Who owns the correctness of this design?

For individual work, this should be you.

## 6. Escalation Path
Where might this design fail later?

Include:
- scale risks
- concurrency risks
- maintenance risks
- AI-generated-code risks
