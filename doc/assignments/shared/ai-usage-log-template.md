# AI Usage Log Template

Use this file to disclose and evaluate AI usage.

## Tool Used
Example: ChatGPT, Claude, GitHub Copilot, Gemini

## Purpose
What did you ask the AI to help with?

## Prompt Summary
Summarize the prompt or include the prompt directly.

## Output Summary
What did the AI produce?

## Accepted
What parts did you use?

## Rejected
What parts did you reject?

## Verification
How did you verify the AI output?

## Risk
What could be wrong even after verification?
